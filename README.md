# 📊 Stock Portfolio Tracker

A simple and elegant web app built using **Streamlit** that allows users to track their stock portfolio in real time using live data from Yahoo Finance.

![image](https://github.com/user-attachments/assets/95e226e0-df25-44a9-847e-d6ec83bdc16c)


## 🚀 Features

- 🔍 Search and track multiple stocks by ticker symbol (e.g., TCS.NS, AAPL, RELIANCE.NS)
- 💹 Real-time stock prices and portfolio value updates
- 📈 Calculates your gains/losses automatically
- 🧼 Clean, user-friendly UI built with Streamlit

## 🛠 Built With

- 🐍 Python
- 🎈 Streamlit
- 📦 yfinance
- 🧮 pandas
